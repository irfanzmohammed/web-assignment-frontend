# Frontend (React + Vite + Tailwind)

This is the frontend of a simple authentication web app built using **React (Vite)** and **Tailwind CSS**.

It includes:

- Signup page  
- Login page  
- Dashboard (Welcome User)  
- Form validation  
- Toast notifications  
- Integration with backend API  

---

## 🚀 Tech Stack

- React (Vite)  
- Tailwind CSS  
- Axios  
- React Router  

---

## ✨ Features

✔ Signup with validation  
✔ Login with JWT token  
✔ Protected Dashboard  
✔ Redirect after login  
✔ Error & success messages using Toast  
✔ Connected to backend API  

---

## 🛠 Setup Instructions

### 1️⃣ Install dependencies
npm install


### 2️⃣ Start development server
npm run dev


### 3️⃣ Update Backend API URL  
Set your backend API URL inside your frontend project (axios config or env file).
